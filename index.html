⭐ Mes notes

Les critères que nous utilisons pour noter les restaurants.

```
```
🍔

Goût

Est-ce que le repas est bon ? Les saveurs, les sauces, les épices et la qualité générale du plat.

```
```
💰

Prix

Est-ce que le prix est intéressant pour un élève ? On compare le prix avec la quantité et la qualité.

```
```
🍽️

Quantité

Est-ce qu'on ressort rassasié ? On regarde la taille du repas et la quantité servie.

```
```
🥗

Qualité

Fraîcheur des produits, cuisson, préparation et qualité générale de ce qui est servi.

```
```
⚡

Rapidité

Combien de temps faut-il attendre avant d'avoir son repas ?

```
```
😊

Service

Accueil, gentillesse, organisation et expérience générale au restaurant.
